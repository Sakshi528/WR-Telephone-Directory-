# Follow-up — 2026-09-12

## 6. Naming-convention spot-checks (no changes needed)

Verified, at the user's request, that organizations whose name contains "Transmission," "Thermal," or "Hydel"/"Hydro" are already 100% consistently categorized to match (22 Transmission, 3 Thermal-named, 1 Hydel-named — all correct). A parallel check for "Generation" surfaced 2 organizations (Raigarh Energy Generation Limited, SKS Power Generation (C.G.) Limited) that intentionally stay in Thermal rather than Generation Company, and one (Odisha Generation Phase-II Transmission Limited) that is genuinely a transmission project despite the word "Generation" in its name — confirmed these should NOT be forced into Generation Company by name alone, since the app's real convention is fuel-type/function based, not literal name matching.

A proposal to reclassify every organization whose name doesn't literally contain a category keyword into "Others" was evaluated (would have affected 169 of 215 organizations — all 8 SLDCs, all 8 RLDCs, all 5 Nuclear plants, all 3 CPSU entries, the Regional Power Committee, etc.) and **not applied** — it would have destroyed correctly-verified categorization and broken the Category filter's usefulness across the app (cascading dropdowns, Custom Email Group builder).

## 7. Area Load Despatch Centre, MSETCL (org 6345) — Others → SLDC

Same reasoning as yesterday's "State Load Despatch Centre, MSETCL" (org 6344) fix: this is a genuine ALDC (Area Load Despatch Centre, Nagpur) under Maharashtra's SLDC hierarchy, not a generic catch-all entity. SLDC count: 8 → 9, Others: 16 → 15.

## 8. Subcategory backfill — every organization now has one

16 organizations had a blank Subcategory (`organizations.region`), so they weren't appearing anywhere on the Categories admin page. Filled in following the established convention (subcategory = the Word H1 section heading text an org falls under):

- 11 self-titled section/container organizations (e.g. "Black Start Facilitated Stations," "Nuclear Power Stations In Western Region," "Western Regional Power Committee," "Western Region Load Despatch Centre") — subcategory set to their own name, since they *are* their own Word heading.
- "Grid Controller Of India Limited" → "NLDC And RLDCs" (matching its siblings under that heading).
- Power Grid Corporation Of India Limited + POWERGRID WRTS-I/II → "Power Grid Corporation Of India Limited" (no real Word section exists for these — see Section 2's CPSU note — so grouped under their own natural real-world parent label instead).
- "NTPC" (the holding-level org, distinct from NTPC Mumbai/Raipur HQ) → self-labeled "NTPC".

Zero organizations left with a blank subcategory as of this report. Subcategory suggestion list (`organization_subcategories`) synced to match via the new "Sync from live data" button/route (`admin.sync_subcategories`).
